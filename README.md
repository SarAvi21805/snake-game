# Snake Game - React + Vite

### Descripción
Implementación del clásico juego Snake utilizando React.

### Instrucciones para Correr
1. Clonar el repositorio.
2. Ejecutar 'npm install'.
3. Ejecutar 'npm run dev'.

### Cómo Jugar
Usa las flechas del teclado para mover a la serpiente y comer los puntos rojos.
